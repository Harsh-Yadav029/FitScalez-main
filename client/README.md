# Fitscalez — Frontend Application

Next.js 15 App Router frontend application with React 19, GSAP animation physics, Lenis smooth scrolling, and a custom CSS variable design system.

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run dev server on http://localhost:3000
npm run dev

# Production build
npm run build

# Start production server
npm start
```

---

## 🔑 Environment Variables (`client/.env`)

```env
NEXT_PUBLIC_API_URL=http://localhost:5000/api/v1
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

---

## 📁 Key Routes

* `/` — Homepage (Vimeo Hero, Trusted Clients Marquee, Horizontal Scroll, Motion Cards, Service Cards, Footer)
* `/about` — Agency story, team, and milestones
* `/services` — Full-stack capabilities & pricing packages
* `/projects` — Case studies portfolio (Walk The Plan, House of Symmetry, FashionWave, GreenLeaf)
* `/blog` & `/blog/[slug]` — 14 Technical guides & articles
* `/careers` — Open positions with interactive application submission
* `/contact` — Client inquiry capture form with live backend ingestion
* `/privacy-policy` & `/terms-of-service` — Complete legal policies
* `/sitemap` & `/sitemap.xml` — Visual and search engine sitemaps
* `/admin/login` & `/admin/dashboard` — Authenticated CRM dashboard
